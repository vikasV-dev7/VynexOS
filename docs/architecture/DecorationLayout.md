# DecorationLayout

`DecorationLayout` is a pure data structure that explicitly defines the exact rectangular bounds for every window decoration element, relative to the window's decorated bounds.

## Components
It contains explicitly defined `Rect` objects for:
- `title_bar`
- `client_area`
- `close_button`
- `minimize_button`
- `maximize_button`
- Borders (`left_border`, `right_border`, `top_border`, `bottom_border`)
- Resize Corners (`top_left_resize`, `top_right_resize`, `bottom_left_resize`, `bottom_right_resize`)

## Principle of Purity
`DecorationLayout` is purely geometric. It purposefully excludes state data such as:
- Colors
- Fonts
- Hover/Pressed states
- Theming

It is exclusively generated by the [[Decoration Layout Engine]] and consumed by downstream systems in accordance with strict [[UI Layout Ownership]].
